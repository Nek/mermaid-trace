# Roadmap

Status: documentation baseline established; product implementation has not started. Stories and criteria are defined in the [spec](specs/source-mapping/spec.md). Complete one implementation story at a time.

| Milestone | Scope | Exit evidence | Status |
|---|---|---|---|
| M0 — Foundation | Select and initialize toolchain; establish SDD artifacts | Pinned tools and locked install verified; setup documented | Complete: docs and dependency setup |
| M1 — Feasibility and format | Choose one diagram type; prove spans and artifact v1 alongside Markdown extraction and VS Code preview hooks | Source-backed backend assessment and one representative mapping proof; exact contracts and fixture expectations agreed | In progress: exact source-span and SVG preservation proof verified; format v1 and Markdown feasibility remain |
| M2 — Static renderer | Implement S1 plus static markdown-it fence integration for the selected subset | SVG opens with scripting disabled; mapping survives serialization; exact Unicode/CRLF spans and repeated occurrences verified | Not started |
| M3 — Optional interaction | Implement S2 against saved SVG; first browser demonstration generated by markdown-it | Click/keyboard selection and reverse highlighting work; cleanup, invalid metadata, and multiple-instance isolation verified in a browser | Not started |
| M4 — Embedding and viewer | Complete S3 and S4, including unified/rehype; package usable entry points | Plain-JS consumer, HTML Markdown page with multiple blocks, and VS Code webview/editor demonstration; renderer absent from interactivity bundle | Not started |
| M5 — Rust parity | Implement S5 against the agreed format | Shared fixtures pass in both implementations; Rust SVG activates in the same JS library; measured performance with methodology | Not started |

M1 has a [deterministic upstream SVG baseline](specs/svg-baselines/spec.md). The [first mapping proof](specs/flowchart-mapping/spec.md) now preserves exact node/edge spans and baseline SVG bytes. Markdown extraction provenance and the stable artifact contract are next. A renderer that merely places guessed locations in SVG does not satisfy M1 or M2. Browser-based rendering may be the initial approach; Node rendering without a browser is not promised.

## Foundation story: toolchain and initialization

**INIT-1:** approved Node.js LTS + pnpm, strict TypeScript/ESM and Node's built-in test runner. Exact versions, acceptance criteria, implementation plan, and verification live in [the toolchain spec](specs/toolchain/spec.md). Add Vite and browser automation with the first Markdown/browser story. No product dependency or empty viewer scaffolding is needed now.

## Later, outside this release

Broader Mermaid coverage, stable identity across edits, source-rewriting visual editing, collaboration, and native bindings/WASM are separate future stories. Their priority depends on demonstrated use, not on completing infrastructure in advance.
