# Roadmap

Status: experimental flowchart producer, independent SVG activation, Markdown provenance and a clickable demo implemented. Stories and criteria are defined in the [spec](specs/source-mapping/spec.md). Complete one implementation story at a time.

| Milestone | Scope | Exit evidence | Status |
|---|---|---|---|
| M0 — Foundation | Select and initialize toolchain; establish SDD artifacts | Pinned tools and locked install verified; setup documented | Complete: docs and dependency setup |
| M1 — Feasibility and format | Choose one diagram type; prove spans and artifact v1 alongside Markdown extraction and VS Code preview hooks | Source-backed backend assessment and one representative mapping proof; exact contracts and fixture expectations agreed | In progress: span/SVG/Markdown proofs verified; stable v1 and VS Code selection boundary remain |
| M2 — Static renderer | Implement S1 plus static markdown-it fence integration for the selected subset | SVG opens with scripting disabled; mapping survives serialization; exact Unicode/CRLF spans and repeated occurrences verified | Experimental flowchart subset and markdown-it demo verified; broader export guarantees pending |
| M3 — Optional interaction | Implement S2 against saved SVG; first browser demonstration generated by markdown-it | Click/keyboard selection and reverse highlighting work; cleanup, invalid metadata, and multiple-instance isolation verified in a browser | ACT-1 complete for experimental format 0 in pinned Chromium; wider browser/format-v1 acceptance pending |
| M4 — Embedding and viewer | Complete S3 and S4, including unified/rehype; package usable entry points | Plain-JS consumer, HTML Markdown page with multiple blocks, and VS Code webview/editor demonstration; renderer absent from interactivity bundle | In progress: DOC-1 mdast/hast document view and browser selection verified; packaging and VS Code remain |
| M5 — Rust parity | Implement S5 against the agreed format | Shared fixtures pass in both implementations; Rust SVG activates in the same JS library; measured performance with methodology | Not started |

M1 has a [deterministic upstream SVG baseline](specs/svg-baselines/spec.md). The [first mapping proof](specs/flowchart-mapping/spec.md) preserves exact node/edge spans and baseline SVG bytes. Markdown extraction provenance is verified; the stable artifact contract remains open. A renderer that merely places guessed locations in SVG does not satisfy M1 or M2. Rendering currently uses a browser; browser-free Node rendering is not promised.

[FORK-1](specs/mermaid-fork/spec.md) replaces parser interception with explicit source maps from [Nek/mermaid](https://github.com/Nek/mermaid/tree/feat/flowchart-source-mappings). [MD-1](specs/markdown-provenance/spec.md) verifies Markdown extraction provenance and synchronous consumption of prepared SVGs. [ACT-1](specs/svg-activation/spec.md) supplies a separate activation module and clickable Markdown demonstration. [DOC-1](specs/document-selection/spec.md) adds the unified mdast/hast document view, rendered-text/heading selection and whole-diagram activation. Next candidates: stable format/security acceptance, reusable package entry points, and the VS Code host boundary. Discussing the upstream API remains pending.

## Foundation story: toolchain and initialization

**INIT-1:** approved Node.js LTS + pnpm, strict TypeScript/ESM and Node's built-in test runner. Exact versions, acceptance criteria, implementation plan, and verification live in [the toolchain spec](specs/toolchain/spec.md). Vite now serves the Markdown demo; Playwright verifies browser behavior.

## Later, outside this release

Broader Mermaid coverage, stable identity across edits, source-rewriting visual editing, collaboration, and native bindings/WASM are separate future stories. Their priority depends on demonstrated use, not on completing infrastructure in advance.
